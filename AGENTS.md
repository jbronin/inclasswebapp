# Project layout

This is a single-file web app. Keep the GitHub Pages entry point, `index.html`,
at the repository root, alongside `AGENTS.md`, `spec.md`, and `prompts.md`.

Use the numbered folders for supporting project files:

- `00_planning/` — notes and sketches.
- `01_data/` — data files.
- `02_validation/` — hand calculations and test cases.
- `03_output/` — screenshots and exported results.

Save every new file in the appropriate root location or numbered folder. Add
files to the root only when they are one of the project-level files listed
above; otherwise choose the matching numbered folder.
